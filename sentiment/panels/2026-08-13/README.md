# Independent model panel

Every model analyzed the identical saved evidence package independently.
Models did not receive other models' outputs and could not browse, write files,
or access the network. These are research comparisons, not investment advice.

Models: GPT-5.2, Cursor Grok 4.6 High, Gemini 3.1 Pro, Claude Sonnet 5 High,
and Kimi K3 High (Chinese model family).
